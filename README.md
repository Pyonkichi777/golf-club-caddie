# Yardage Caddie

残りヤードから使用クラブを推奨する、1人用のPWA。
コース上で手袋をしたまま片手で使うことだけを考えて作ってある。

```
残り 128m  →  実効 140yd  →  実戦基準 6I（8yd足りない） / ナイス基準 6I（+5yd余る）
```

## できること

**1. 実効距離の補正**
見た目の残り距離を、実際に打つべき距離へ翻訳する。高低差・風・ライ・気温の4つ。

**2. 2つの基準を並べて出す**
「実戦基準」＝平均的な当たりで届く番手。「ナイス基準」＝会心の当たりで届く番手。
どちらか一方だけを出さないのは、手前がハザードの時と奥がOBの時で選ぶべき番手が逆になるため。

**3. 刻む判断**
ハザードまでの距離を入れると、越える番手と刻む番手を計算する。
刻んだ先の残り距離がどの番手になるかまで出すので、「なんとなく刻む」がなくなる。

**4. ギャップの可視化**
番手間が15yd以上空いている区間を出す。クラブの買い足し判断に使える。

**5. 持っていく3本**
推奨を中心に上下1番手ずつ出す。番手を読み違えても、当たりが悪くても、
カートまで戻らずに次が打てる組み合わせ。

**6. 得意・苦手**
ズレが1番手（10yd）以内なら得意な番手を優先し、苦手な番手は避ける。

```
評価 = |距離のズレ| ＋ 苦手ペナルティ(5yd) − 得意ボーナス(5yd)   → 最小の番手を推奨
乗り換えられるのはズレが10yd以内の番手だけ
```

例（得意＝6I・7I、苦手＝1W・5UT）:

| 実効距離 | 距離だけなら | 推奨 | 理由 |
|--:|:--|:--|:--|
| 142yd | 5UT（+8yd） | **6I**（10yd足りない） | 苦手な5UTより得意な6I |
| 143yd | 5UT（+7yd） | **5UT** | 6Iは11yd足りず、1番手を超える |
| 115yd | 8I（5yd足りない） | **7I**（+7yd） | 得意な7Iを優先 |

乗り換えたときは、距離だけで選んだ番手を**必ずカードに併記**する。アプリが黙って判断を変えたように見せないため。
手前に池やバンカーがあるときは距離優先で選ぶよう、注意書きも出す。

普段の得意/苦手は `clubs.json` の `skill`（`good` / `normal` / `weak`）。
ラウンド中に「今日は7Iが当たらない」と思ったら、距離表の画面で**今日だけ**上書きできる。
上書きは端末に保存され、日付が変わると自動で普段の設定に戻る。

## キャリーとトータルの使い分け

**「ピンに近いか遠いか」ではなく、「着弾点そのものが目標か、手前に落として転がすか」で決まる。**

| 狙い | 基準 | 場面 |
|:--|:--|:--|
| **グリーンに乗せる** | キャリー | グリーンに直接乗せる／手前のバンカー・池を越す。落ちた場所が結果を決める |
| **手前から転がす** | トータル（キャリー＋ラン） | フェアウェイに置く／刻む／グリーン手前から転がし上げる |

しかも、この区別が効くのは**遠い場面ほど**。ランは番手で大きく違う。

```
1W  +30yd  ← キャリーとトータルが別物
5UT +15yd
7I  +15yd
PW   +8yd
56°  +5yd  ← ほぼ同じ。区別する意味がない
```

画面上では常にキャリーとトータルの両方を出し、いま合わせている側を太字にしている。
トータル基準に切り替えているときは、グリーン手前のハザードを見落とさないよう注意書きが出る。

## 設計の前提

| 前提 | 理由 |
|:--|:--|
| **ヤード既定（メートルへ即切替）** | コースの杭はヤードが基本。ただし乗用カートのナビなどメートルのこともあるので、単位は常時表示しトグルを距離のすぐ横に置く |
| **狙いで基準を切り替える** | 上記のとおり。既定はキャリー基準 |
| **ライトテーマ固定** | 直射日光下では明るい面のほうが読める。端末がダークモードでも切り替えない |
| **補正はボタン選択のみ** | 距離計を持たない前提なので入力誤差が±5〜10ydある。それより細かい補正は誤差に沈む |
| **完全オフライン動作** | コースは電波が届かないことがある。外部CDNへの依存をゼロにしてある |

## 数字の出どころ

すべて `clubs.json` にある。1本ごとに `source`（いつ・何で測ったか）と `confidence`（実測か推定か）を持つ。
画面上でも★の数で実測と推定を区別して出す。**根拠のない数字は載せない。**

現時点では8本中6本が推定値なので、アプリの精度もそこで頭打ちになる。
弾道計測機のある練習場で各5球ずつ測れば埋まる。

## 距離を更新する

`clubs.json` を直接書き換えてコミットする。それだけ。

```json
{
  "id": "6i",
  "carry_game_yd": 132,   // 実戦基準（推奨の既定値）
  "carry_best_yd": 145,   // 好球時（ナイス基準）
  "run_yd": 14,           // ラン。トータル基準と刻みの判定に使う
  "skill": "good",        // 得意 good / 普通 normal / 苦手 weak
  "shots_measured": 0,
  "confidence": "estimated",   // "measured" にすると★★☆になる
  "source": "7Iからの内挿推定"
}
```

補正係数も同じファイルの `corrections` にある。実際に使ってズレを感じたら、ここを調整する。
符号の定義は `formula` ブロックに書いてある。**ここを読まずに係数を触ると番手が逆に出る。**

## iPhoneに入れる

1. Safariで公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 初回だけオンラインで一度開く（データとフォントがキャッシュされる）

以後は機内モードでも動く。

## 中身

```
index.html    画面の骨格
styles.css    見た目（ライトテーマ固定・44pt以上のタップ領域）
app.js        計算と描画。数値は一切持たず、すべてclubs.jsonから読む
clubs.json    クラブ距離データと補正係数の唯一の正
sw.js         オフライン用のService Worker
fonts/        表示書体（自己ホスト・35KB）
icons/        アイコン
```

ビルド不要。フレームワークなし。`index.html` を開けば動く
（Service Workerだけはhttps配信またはlocalhostが必要）。

ローカルで動かすなら:

```sh
python3 -m http.server 8777
# → http://localhost:8777
```

## 置かないもの

このリポジトリは公開なので、以下は入れない。

- 氏名・ハンドルネーム
- **コース名・ラウンド日・位置情報**
- レッスンのプロ名・店舗名

計測の出どころは「2026-07 練習場計測」程度の粒度に留める。
`clubs.json` の `privacy` ブロックに同じことが書いてあるので、コミット前に読むこと。
